When I'm exploring knowledge on the Internet, I often come across with people whose accomplishments I find interesting, so I make a poster containing images of those people and a quote from them or a description of their accomplishments, print it, and hang them in my room's wall to be inspired by them. Sometimes some friends request a copy of those infographies, so I'm sharing those infographies in this repository, so that my friends can have a copy of those infographies too.

All JPG files in this repository were exported at 300ppi from the SVG files.

You can use [Inkscape](https://inkscape.org/) to edit the SVG files.

If you want to edit the SVG files, you will need to install the font "Computer Modern" to see the text. In this repository, there's a file called `font-computer-modern.zip` which contains the fonts that are used inside the images.

The size of the canvas in some SVG files is bigger than A4, so the corresponding JPG image is not intended to be printed in A4. You could print those JPG images in A4, but some QR codes and some text would get really small. If your printer only prints A4 and you want to print such images, you would need to split the JPG image into multiple JPG images that have the size of a A4, print the multiple parts and then merge them together using adhesive tape.
